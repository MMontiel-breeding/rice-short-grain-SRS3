# Genetic Mapping of a Putative Spontaneous Short-Grain Mutation Identifies a Predicted Loss-of-Function Allele of SRS3 in Rice

## Overview

This repository provides R scripts and the input datasets needed to reproduce the grain morphology, F₂ phenotypic segregation, and LSU500 single-marker association analyses associated with the manuscript by Montiel M., Angira B., Richards J.K., and Famoso A.

Other supporting tables and figures are provided with the manuscript. Tables used as script inputs are also included here so the analyses can be run using the repository files.

WT denotes the wild-type, long-grain phenotype; SG denotes the short-grain phenotype.

## Repository contents

This repository contains the following R scripts and the input datasets needed to run them.

### R scripts

1. `01_Grain_Morphology_QC_and_Statistical_Analysis.R`
2. `02_F2_147_Segregation_and_LSU500_Association_Analysis.R`
3. `03_Avant_F2_Phenotypic_Segregation_Analysis.R`
4. `04_F2_Complete1031_Phenotypic_Segregation_Analysis.R`

### Input datasets

1. Raw grain morphology measurements.
2. Marker information for the LSU500 SNP panel.
3. Phenotypes and LSU500 genotype calls for the initial 147 IC206-derived F₂ plants.
4. Grain phenotypes for the 100-plant Avant-derived F₂ population.
5. Grain phenotypes and chromosome 5 marker genotypes from the expanded 1,031-plant IC206-derived F₂ population.
