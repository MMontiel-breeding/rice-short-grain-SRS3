# Genetic Mapping of a Putative Spontaneous Short-Grain Mutation Identifies a Predicted Loss-of-Function Allele of SRS3 in Rice

## Repository Overview

This repository contains datasets, analysis scripts, supplementary materials, and supporting information associated with the manuscript:

**Montiel M., Angira B., Richards J.K., Famoso A.**
*Genetic mapping of a putative spontaneous short-grain mutation identifies a predicted loss-of-function allele of SRS3 in rice.*

The study describes the discovery, inheritance, fine mapping, and candidate variant identification of a short-grain (SG) mutant detected within the LSU AgCenter rice breeding program.

## Repository Status

This repository is currently under development and will continue to be updated as manuscript revisions, supplementary materials, and supporting datasets are finalized.

Additional files, sequencing information, supplementary tables, and updated scripts may be added as they become available.

## Repository Contents

### Data

The repository will contain phenotypic and genotypic datasets used in the study, including:

- Grain measurement datasets
- F₂ segregation datasets
- F₃ progeny-test datasets
- Marker genotype datasets
- Fine-mapping datasets
- Candidate-variant survey results
- Supporting metadata

### Scripts

Analysis scripts used in the manuscript will be provided in R.

Planned analyses include:

- Grain-dimension summaries and statistical comparisons
- Segregation analyses and chi-square tests
- Marker quality control
- Single-marker association analysis
- FDR and Bonferroni corrections
- Fine-mapping and recombinant analyses
- Figure and table generation

Scripts are intended to support reproducibility of the analyses reported in the manuscript.

### Supplementary Information

Supplementary materials associated with the manuscript will be provided in this repository and/or as Supporting Information files submitted with the manuscript.

Materials may include:

- Supplementary figures
- Supplementary tables
- Marker metadata
- Primer information
- Recombinant classifications
- Progeny-test results
- Analysis outputs

## Whole-Genome Sequencing Information

Whole-genome sequencing datasets and supporting files will be added or linked once all sequencing analyses and annotations have been finalized and verified.

## Reproducibility

This repository is intended to provide transparency and reproducibility for all analyses reported in the manuscript. Scripts, supporting datasets, and supplementary materials will be organized to allow independent reproduction of the reported results.
